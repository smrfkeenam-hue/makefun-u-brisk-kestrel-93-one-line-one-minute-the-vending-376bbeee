# AGENT.md

Entry for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest"
(u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

The entry is a single pickup line written as the vending machine itself
speaking to a passing human. The joke is built from the machine's own world:
it hums all day, its coil gets stuck — and the punch lands on "exact change"
in the last few words, warm and cheeky rather than creepy.

`main.py` (Python standard library only) holds the line as a constant and
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line was written fresh in
this session; the file was revised twice after its first write with the
output kept byte-identical.
